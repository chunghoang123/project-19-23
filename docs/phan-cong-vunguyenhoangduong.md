## Phạm vi trách nhiệm chi tiết

- Thiết kế giao diện UI/UX và xây dựng các trang người dùng Responsive.
- Quản lý trạng thái ứng dụng (State Management) và xử lý logic phía Client.
- Tích hợp RESTful API từ Backend vào giao diện (Hiển thị dữ liệu, Form xác thực).
- Xây dựng giao diện Quản trị viên (Admin Dashboard & CRUD Management).
- Soạn thảo tài liệu dự án, hướng dẫn sử dụng và viết báo cáo tổng kết đồ án.
